# Atlas data model

The canonical schema and editing rules are in [Editing Atlas](data/atlas/README.md). Keep current organizational facts in the CSVs, not in this document.

- `data/atlas/governance.csv` defines roles, circles, hierarchy, and energizers.
- `data/atlas/domains.csv` defines work and its hierarchy.
- `data/atlas/relationships.csv` records ownership, support, and succession by stable ID.
- `atlas-data.js` is generated by `python3 build.py` and is never edited independently.

All views use that generated data. People is derived from governance assignments, and both sides of ownership links use `atlas-ownership.js`.

See [Atlas development](scripts/ATLAS.md) for verification commands and view behavior.
